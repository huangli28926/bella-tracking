# 1. Goal

Implement a deterministic:

```text
DataDep Contract Interpreter
```

that converts:

```text
accept-chain.target.dataDeps[]
```

into:

```text
Runtime Expected Values
```

and compares them with:

```text
Tracking Actual
```

The final execution flow MUST be:

```text
resolved DataDep
↓
Runtime Evidence
↓
Runtime Expected Value
↓
Tracking Actual
↓
Expected / Actual Compare
```

# 2. Core Principle

P2-2 MUST only consume:

```text
target.dataDeps[]
```

and runtime evidence.

P2-2 MUST NOT infer runtime sources from:

```text
parameter.expression
parameter.sourcePath
parameter.evidence
parameter.hint
parameter.confidence

insertHint
eventName
evtId
paramKey semantic meaning
```

For example, this is forbidden:

```js
if (dep.paramKey === 'housedel_id') {
  expected = query.housedelCode
}
```

This is also forbidden:

```js
if (parameter.expression.includes('query')) {
  // infer URL source
}
```

The runtime source MUST be determined only by the DataDep Contract.

# 9. Runtime Window

The runtime window is deterministic.

For every target:

```text
enter path
↓
API collector remains active

finish sharedSteps
↓
targetRuntimeStart = now
↓
capture URL/window expected snapshot
↓
execute trigger
↓
capture tracking event
↓
wait for tracking collection to finish
↓
targetRuntimeEnd = now
↓
resolve API DataDeps using current target window
```

The API store is:

```text
path-level accumulated store
```

Do NOT clear the API store before every target.

Instead filter responses by:

```text
targetRuntimeStart <= response.t <= targetRuntimeEnd
```

# 13. URL Resolver

Runtime rule:

```text
dep.queryKey
↓
pre-trigger URL query
↓
expected value
```

Example:

```js
function resolveUrlDataDep(dep, ctx) {
  const query = ctx.urlSnapshot && ctx.urlSnapshot.query || {}

  if (!Object.prototype.hasOwnProperty.call(query, dep.queryKey)) {
    return {
      paramKey: dep.paramKey,
      from: 'url',
      status: 'missing',
      code: 'RUNTIME_URL_QUERY_MISSING',
      runtimeSource: {
        kind: 'urlQuery',
        queryKey: dep.queryKey
      }
    }
  }

  return {
    paramKey: dep.paramKey,
    from: 'url',
    status: 'resolved',
    value: query[dep.queryKey],
    runtimeSource: {
      kind: 'urlQuery',
      queryKey: dep.queryKey,
      href: ctx.urlSnapshot.href
    }
  }
}
```

Forbidden:

```js
dep.queryKey || 'housedelCode'
```

Forbidden:

```js
if (dep.paramKey === 'housedel_id')
```

# 14. URL Query Semantics

The following rules are fixed.

## Missing key

```text
?id is absent
```

Result:

```text
RUNTIME_URL_QUERY_MISSING
```

---

## Empty value

```text
?id=
```

Result:

```text
resolved("")
```

Empty value is still a real runtime value.

---

## Duplicate query key

Example:

```text
?id=1&id=2
```

Preferred behavior:

```text
RUNTIME_URL_QUERY_AMBIGUOUS
```

Do NOT arbitrarily choose first / last.

If the current repository parser structurally prevents duplicate detection, preserve current parsing for this phase and document the limitation in the implementation summary.

Do NOT expand scope only to redesign query parsing.

# 15. windowPath Resolver

First phase supports only:

```text
runtime.kind = windowPath
```

For both:

```text
from=user
from=page
```

the runtime execution mechanism is the same.

Example:

```js
async function resolveRuntimeSelector(dep, runtime, ctx) {
  if (!runtime) {
    return {
      paramKey: dep.paramKey,
      from: dep.from,
      status: 'error',
      code: 'RUNTIME_SELECTOR_MISSING'
    }
  }

  if (runtime.kind !== 'windowPath') {
    return {
      paramKey: dep.paramKey,
      from: dep.from,
      status: 'error',
      code: 'RUNTIME_SELECTOR_UNSUPPORTED'
    }
  }

  // read snapshot / pre-trigger runtime
}
```

Do NOT support:

```text
redux
context
hook
localStorage
cookie
DOM
React state
```

unless the DataDep Contract is explicitly expanded in a future phase.

# 16. getByPath Semantics

First phase MUST use deterministic path traversal.

Rules:


# 18. API Candidate Rule

A response is a valid candidate only when all conditions are true:

```text
within current target runtime window
+
response.url.includes(dep.api.urlIncludes)
+
HTTP status is 2xx
+
body JSON parsing succeeded
+
dep.api.field exists
```

This rule is authoritative.

Do NOT use looser candidate selection.
